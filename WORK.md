- 2026-07-21 · **QR Code de verdade: encoder próprio + imagem + página de visualização.** Os endpoints `.../base64` devolviam um **PNG de 1x1 pixel transparente** para qualquer entrada — HTTP 200, campo `base64image` plausível e imagem vazia; e o `location/{id}/base64` ainda ignorava o `locationId` recebido. Quem consumisse esperando um QR recebia um pixel, sem erro nenhum.
